# 26UNEDC-Vision

2026 全国大学生电子设计竞赛机器人视觉项目。

本项目主要负责机器人视觉感知部分，实现钢球目标检测、目标坐标提取以及与主控制器之间的数据通信，为机器人运动控制提供目标位置信息。

---

## 项目功能

- 基于 YOLOv8 实现钢球目标检测
- 使用摄像头进行实时图像采集
- 提取检测目标的中心坐标
- 将目标坐标发送至主控制器
- 完成视觉检测、坐标计算与通信流程联调
- 对模型实时运行性能进行测试和优化

---

## 系统流程

```text

    ↓

    ↓
获取目标检测框
    ↓
计算目标中心坐标
    ↓
通信模块发送坐标
    ↓
MSPM0G3507 主控制器
    ↓
机器人运动控制
